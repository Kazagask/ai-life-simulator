# 战斗交互稿

> 配套 ADR-076（战斗表现层）。本文只写**玩家怎么操作、屏幕怎么回应**，
> 不重复表现层的字段与配色；特效细节见原型 `docs/prototypes/battle-fx.html`。
> 状态：设计稿，未实现。

---

## 0. 一屏是什么

竖屏 420（`apps/web` 上限 520），自上而下五块，**顺序不能变**：
先看「还能不能打」，再看「打谁」，最后才是「怎么打」。

```
┌──────────────────────────────┐
│ ⚔ 战斗 · 第 2 回合   [暴击×1] │ ← 回合条：回合数 / 战果计数 / 状态标签
├──────────────────────────────┤
│ 五条悟  [六眼][无下限]        │
│ 生命 ████████░░ 207/221      │ ← 我方资源：可点＝「选自己」的落点
│ 咒力 █████████░ 180/200      │
├──────────────────────────────┤
│ 二级咒灵  敌方        320/320 │ ← 敌方列表：每张卡都是可选目标
│ ████████████████  [适应×2]   │
│ 魔虚罗    中立        345/345 │
│ ████████████████  [适应×1]   │
├──────────────────────────────┤
│ 术式「苍」      术式反转「赫」│ ← 行动区：2 列；宽屏也不超过 2 列
│ 虚式「茈」      黑闪          │
│ 解              反转术式      │
└──────────────────────────────┘
```

**为什么敌方列表在行动区上方**：手指从下往上够，卡片在中间，
数字与标签才有地方落；行动区贴底，是拇指区。

## 1. 状态机

| 状态 | 进入条件 | 可点 | 离开 |
|---|---|---|---|
| `pick` | 打开战斗 / 上一段播放结束 | 技能、目标、道具、逃跑 | 点技能 → `target`（群体直接 `submit`） |
| `target` | 点了**单体**技能 | 目标卡、「取消」、再点一次同技能 | 点目标 → `submit`；点空白 → 回 `pick` |
| `submit` | 已提交，等引擎返回 | 全部禁用（busy） | 拿到 snapshot → `play` |
| `play` | 收到 `battle.fx` | 任意位置＝跳过当前段 | 播完 → `pick` 或 `over` |
| `over` | `battle.over !== null` | 「离开战场」 | 下一事件 |

> `cannot_act`（眩晕这类）**不改状态机**，只把行动区整体盖住 ——
> 引擎不报错、只跳过你的动作，前端必须主动告知，否则玩家以为「点了没反应」。

## 2. 一次出手的时序

| 时刻 | 屏幕 | 备注 |
|---|---|---|
| 0ms | 技能按钮按下态（下沉 1px、描边变亮） | 纯 CSS，不等网络 |
| 0ms | 若单体：目标卡出现锁定框；当前目标高亮 | 默认选中第一个存活敌对 |
| +0 | 点目标 → 立即 `submit`，全屏 `busy` | **不要**等动画播完再提交 |
| ~RTT | snapshot 回来，`battle.fx.casts[]` 一并到达 | 权威状态此刻已落库 |
| +0 | 施法段：施法者掌心蓄力（200–360ms） | 见 ADR-076 §3.0 |
| +200 | 轨迹段：刃/线/扇从施法者长出来 | 150–420ms，按类型 |
| +命中 | 受击段：火花 / 盾 / 斩空 | 与轨迹末端同一帧 |
| +命中 | 结算段：数字 pop + 后缀 + 标签 | 260ms，向上飘 950ms |
| +命中 | 连击第二段（同 cast 内 +150ms） | 群体按目标错开 |
| 结束 | 解锁，回到 `pick` | 总时长上限 900ms（快速 300ms） |

**硬规则：状态先落库，动画只是回放。** 动画卡住、被跳过、被切后台，都不影响结果。

## 3. 目标选择

| 技能 `target` | 默认 | 交互 | 说明 |
|---|---|---|---|
| `enemy` | 第一个存活敌对 | 点卡切换 | 中立并入敌对（`campsOf` 同一份） |
| `ally` | **不选** | 点自己或友军；再点一次取消 | 「没选」与「选了自己」必须能区分 |
| `all_enemies` | 无需选择 | 点技能直接提交 | 目标由引擎算，前端不猜 |
| `self` / `none` | 无需选择 | 直接提交 | — |

**合法目标为空**（`legalTargets === []`）：按钮**不隐藏**，置灰 + 一行原因，
原因文案由投影给（`legalTargetNote`）。藏起来等于告诉玩家「没有这个技能」。

## 4. 播放层

- **游标**：客户端记 `lastSeq`；只播 `seq > lastSeq` 的 cast。读档时把游标置为当前最大值 ——
  否则一进战斗就炸一屏数字。
- **跳过**：`play` 状态下点任意位置 → 当前 cast 跳到终帧（数字直接落地），不再排队。
- **打断**：新的 cast 到达时，旧 cast 立即跳到终帧再播新的。玩家连点不该看到动画排队。
- **不阻塞**：播放层 `pointer-events: none`，只有「跳过」的监听挂在容器上。
- **切后台**：`visibilitychange` 回到前台时，把游标推到最后，不补播。

## 5. 多目标结果同屏

一次群体可能同时出现「命中 / 未命中 / 无效 / 暴击」四种结果。
**每个目标各自一套**，互不覆盖：

```
┌──────────────────────────────┐
│ 二级咒灵              -168   │ ← 命中：数字 + 受击
│ ███████░░░░░  152/320        │
├──────────────────────────────┤
│ 魔虚罗      MISS     345/345 │ ← 未命中：没有数字、没有受击
│ ████████████████             │
├──────────────────────────────┤
│ 改造咒灵    免疫     180/180 │ ← 无效：没有数字、有盾
│ ████████████████             │
└──────────────────────────────┘
```

- **数字位置**：卡右缘、垂直居中偏上（`t.y + 22`），右对齐向左生长（窄屏不出界）。
- **避让**：同目标多段纵向错开 32px；不同目标各贴各卡，不跨屏。
- **标签位置**：数字下方 8px；黑闪是两行（`黒閃` / `BLACK FLASH`）。
- **先出的先落**：按 `seq` 顺序，不按 y 坐标排序 —— 玩家要知道「先打的是谁」。

## 6. 边界与异常

| 情形 | 表现 | 不能做的事 |
|---|---|---|
| 资源不足 | 按钮置灰 + 消耗数字标红 | 不弹窗、不禁用整块行动区 |
| 技能被封印 | 照常列出 + 原因（`seal.text`） | 不隐藏、不改灰到看不清 |
| 无法行动 | 行动区盖一层 + 「硬撑」出口 | 不静默跳过回合 |
| 不能逃跑 | 按钮常显但禁用 + 原因 | 不给按钮＝玩家以为没这个选项 |
| 战败 | 定格 + 结算层；`hpOnDefeat` 决定落点 | 不自动跳过失败 |
| 胜利 | 同上 + 战评（若有） | 不在播放中弹结算 |
| 逃跑失败 | 走一回合，不出战场 | 不重复扣资源 |
| 空目标（敌方全灭） | 立即判胜，不进 `target` | 不停在「请选择目标」 |

## 7. 无障碍与设置

| 项 | 行为 |
|---|---|
| 减少动画（含 `prefers-reduced-motion`） | 轨迹 120ms 淡出、无位移、无抖动、无闪屏；数字直接出现 |
| 快速战斗 | 总时长压到 300ms；**数字与后缀照旧** |
| 关闭闪光 | 只关闪屏与发光，不关数字 |
| 色盲 | 每种语义另有形状冗余（箭头/圆头/虚线/盾） |
| 字号 | 数字最小 28px；标签最小 10px |

**这三项是闸，不是层**：模板写什么都盖不掉（ADR-076 §11）。

## 8. 验收清单

- [ ] 点技能 → 选目标 → 提交，**不超过 2 次点击**（群体 1 次）
- [ ] 提交后到动画开始，延迟只来自网络，没有本地排队
- [ ] 播放中连点，不出现第二段动画排队
- [ ] 读档进入战斗，不重放任何历史特效
- [ ] 群体 3 目标打出「命中 / 未命中 / 无效」，三者视觉可区分
- [ ] 同目标两段伤害，数字不重叠
- [ ] 减少动画开启后，仍能看清伤害数值与后缀
- [ ] 眩晕回合，玩家能看出「这一回合不是 bug」

## 9. 未决

1. **「取消」入口**：`target` 状态点空白取消，还是必须有显式按钮？（触屏误触率高，倾向显式按钮）
2. **跳过的手势**：点任意位置 vs 双击 vs 右上角按钮。点任意位置最省事，但会和「点目标看详情」打架。
3. **多段播放的节奏**：现在按 `seq` 150ms 一段；长盘（召唤流）可能一次返回 6 段，需要上限。
4. **战评与胜利结算的先后**：结算面板在播放后立即弹，还是等玩家点「继续」。
