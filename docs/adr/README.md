## 一、六个模块

| 文件 | 管什么 | 一句话不变量 |
|---|---|---|
| `10-开局与角色.md` | 开局 DAG、加点、`as` 借名、开局参数 | 开局发生在世界**之前**：`commit` 前没有 `WorldStateV2` |
| `20-事件与世界时间.md` | 事件链、出场时点、世界时间表、章节推进 | 世界自己会往前走，不靠玩家踩分支 |
| `30-战斗.md` | 命中/闪避、召唤、中立、胜负条件、装备授予 | 一个回合 = 玩家一次行动；敌人也照同一套规则打 |
| `40-属性资源与状态.md` | 属性 kind、资源、状态施加/时长/层数 | 定义零时长，时长只写在**施加点** |
| `50-关系与演员.md` | 关系边与 `scope`、演员同构、能力流转 | 关系是事实；self 只有一个权威实体 |
| `60-表现层与仪器.md` | 投影 VM、样式词表、封印文案、`inspect` | 投影只读；同一个数只写一遍 |

**改代码前的查表路径**：症状 → 模块 → 该模块的「不变量」段落。每个模块开头都先列不变量，
再列决策；不变量被违反时，先怀疑自己改的那行，而不是怀疑文档。

## 三、已被推翻的部分（读档案时要小心）

档案是**当时的**决策，下面几条后来被改掉了。模块文件里已经是改后的口径，
但翻 `archive/` 的旧文时会撞见旧说法：

| 旧说法 | 在哪 | 现在 |
|---|---|---|
| 召唤物走「咒灵数量池 + 账本」，阵亡回补、召回返还、`consumeResource` 扣池 | ADR-012 D6 / B-07 落地纪要 | **整条撤掉**（ADR-013）：只花 MP，阵亡不回补，稀缺性由场上 `limit` 表达；英雄档阵亡即 `lostSummons` |
| 状态两档 `stack｜unique` 里的 `refresh` | ADR-009 | `refresh` 退役，只剩 `stack`（按 `stacking` 叠层）与 `unique` |
| 状态时长写「回合」，`cureConditions.restTurns` | ADR-009 前的世界 | 时长写施加点、单位是世界时间；`restTurns` → `restDays` |
| `visibility` 四档表达关系可见性 | ADR-007 D2 前 | `scope: public｜limited｜private` + `knownBy`，`relationVisibleTo` 唯一判定入口 |
| 技能用不了就**不显示** | ADR-013 初版 | 照常列出 + `seal {code,text}` 封印（ADR-015） |
| `relationEdge.value` 可写「npc → 玩家」的强度 | ADR-017 前 | 这种强度只存 `npc.relationship` 标量；边上的 `value` 只服务非 self 端点 |
| 中立召唤物也参与 `lostSummons` | ADR-013 | 跳过中立（ADR-014 D4）：未调伏的不在名册里 |

## 四、写新 ADR 的规矩

- **先判归属**（`specs/SPEC.md` §1.6）：一个世界用 → 模板；多个但不是全部 → `extensions/`；
  全部都用 → `core`。**先模板后上提**，不预判复用。
- **编号继续往后排**：新决策在 `archive/` 里从 `ADR-018` 起写原文，同时**当场**把结论并进对应模块文件。
  模块文件是给人读的现行口径，档案是给「为什么当时那么想」留的证据 —— 两份都要，但只有模块文件会被当权威引用。
- **跨模块的决策**（如 006 拆三处）：在模块文件里各写自己那一半，开头互相指路。
- **改协议的判据**：数据模型 / 技术栈 / 目录结构 / 游戏规则 —— 命中一条就先立 ADR 再动手（`.workbuddy/ENGINEERING.md` §6）。
