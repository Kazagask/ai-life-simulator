四段分层原型 v4

一次出手拆成 施法 → 轨迹 → 受击 → 结算，四层各自独立、可被模板单独覆盖。

宿傩斩击、免疫盾牌、黑闪雷电裂纹都归受击层；miss 与抵抗只改轨迹的收尾，不产生受击段。

下方「分层实验台」每次只播一层；「全链路」按顺序合成。手机上点按钮即可。

模板怎么配（全部可覆盖）

skills:
  sk-gojo-blue:
    presentation:
      cast:   { preset: charge,  color: "#7C8CFF" }
      trace:  { preset: arrow,   color: "#7C8CFF", width: 2 }
      impact: { preset: burst,   color: "#FF6B7F" }
      result: { size: 28, stroke: 1.4, suffix: auto }

四层各取一个 preset，只覆盖写了的字段；preset 是引擎词，颜色是模板词。

① 施法② 轨迹③ 受击④ 结算

① 施法 cast

默认 none · 只有召唤 / 奥义需要

② 轨迹 trace

施法者 → 目标 · 只有攻击/治疗有

③ 受击 impact

目标身上 · 打没打中看这里

④ 结算 result

数字 + 后缀 + 标签 · 不染色
