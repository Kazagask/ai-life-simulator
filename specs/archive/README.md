## 允许读的两种情形

1. 用户点名要看某个历史决定的过程；
2. 排查「为什么当初这样设计」且 ADR 正文不足。

两种情形都需要**先声明在读哪一份、为什么**。不要递归扫描整个目录。

## 冲突处理

`archive/` 与代码冲突时，**以代码为准**。发现历史文档与现行实现不符，属于正常现象（文档是当时的快照），不要据此改代码，也不要回改历史文档。
