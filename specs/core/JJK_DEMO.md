# Demo 世界模板：咒术回战平行世界

## 1. Demo 定位

用《咒术回战》的世界设定验证通用模拟器。它是一个可偏离原作的平行世界模拟，不以复述原作剧情为目标。

初始建议：2006 年东京咒术高专时期作为可选起点；玩家可创建原创角色，也可选择模板提供的角色身份。原作人物和事件作为世界背景/事件素材，不应成为强制主线。

## 2. 模板必须提供的配置

- `world.config`：世界名称、简介、难度、初始日期、世界规则版本
- `time.config`：历法、年龄阶段、默认步长、特殊事件时间精度
- `rules.config`：咒术能力、任务、伤害/恢复、组织规则（P0 只实现必要子集）
- `characters/`：NPC 初始属性、人格、目标、关系、知识与秘密
- `events/`：原作背景事件、日常事件、随机事件、动态事件链
- `locations/`：高专、城市地点等
- `narrative/`：语气、叙事视角、文本长度约束

## 3. Demo P0 场景

玩家创建一名原创咒术师或学生角色，在东京咒术界生活与成长。
可进行：
- 上课/训练
- 与角色交往
- 接受或拒绝任务
- 调查咒灵/异常事件
- 休息、等待、旅行
- 自由文本描述行动（解析为结构化候选行动）

P0 不要求完整复刻术式系统或复杂战斗。优先证明世界时间、NPC 行动、事件池、信息差和人生评价能够形成闭环。

## 4. 原作事件与蝴蝶效应

- 原作事件可作为模板事件，不是不可改变的固定脚本。
- 事件是否发生、何时发生、结果如何，取决于当前世界状态和玩家/NPC 的历史行动。
- 玩家行为可以让事件提前、延迟、变形、失败或不再发生。
- 必须保留 `canonDeviation` 或等价指标，记录世界与参考时间线的偏离程度。
- 不得为了“拉回原作”而覆盖玩家已造成的因果结果。

## 5. 角色与信息

NPC 具有公开资料和私有资料：
- 公开：身份、可观察属性、公开关系
- 私有：真实目标、秘密、未知能力、未公开关系、掌握的情报
- 玩家视角：仅返回玩家已知/可推测的信息

## 6. 内容边界

该模板用于验证系统能力。不要把原作长篇文本、漫画台词或动画脚本复制进仓库。人物/事件数据应以简短结构化摘要和原创描述表达。
