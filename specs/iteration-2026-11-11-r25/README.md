## 用户原始裁决

1. **事件模型**：轮次槽位唯一；触发二分为立即触发（不入队）与延时触发（按时间窗开始入队、出队时判定、排序 = 开始 asc ＞ 结束 asc（空视为最大）＞ 入队序）；模板可写固定时间段或相对时间；退役「x 轮后触发」；`schedule` 初始化即入队；`pool` 保持最后触发且只能产出延时事件；**延时事件丢失导致的断链，必须在链状态判定时检查时间队列**。
2. **NPC 系统**：投影与生命周期解耦（开局已死亡的重要角色也能上屏）；生命周期 `spawn → alive → dead` 决策生成/行动跳过/事件触发/参战，**默认判活、模板不写**，且不与业务语义耦合（失联也是 dead）；年龄由出生时间动态计算，**三种时间模型默认都要支持**；关系不止好感度，还有亲属/朋友/师徒/自定义，亲属与师承由「记录双亲 / 师父」推导。

## 2026-11-12 评审修订（要点）

| 项 | 裁决 |
