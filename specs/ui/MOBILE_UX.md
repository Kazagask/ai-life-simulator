# 竖屏移动端 UI/UX 规格 V0.1

## 1. 体验原则

- 竖屏优先、单手操作、叙事优先。
- 信息密度适中，以卡片和时间线呈现。
- 复杂详情使用 Bottom Sheet，不在主界面堆叠全部字段。
- 底部 Tab 导航。
- 主界面优先回答：我是谁、现在发生什么、我能做什么、世界有哪些变化。

## 2. 一级导航

1. 人生：玩家状态、当前时间、行动入口、人生阶段评价
2. 人物：关系网络、人物列表、可见资料、已知秘密/传闻
3. 世界：地点、组织、当前世界动态、事件链
4. 记录：人生时间线、事件日志、重要选择、评价

## 3. 核心交互

- 行动入口：常用行动快捷卡 + 自由文本输入。
- 推进控制：单步推进、快速推进、暂停；指定时间推进可作为次级入口。
- 事件卡：显示标题、发生时间、玩家可见摘要、可执行选项。
- 人物详情：Bottom Sheet 展示关系、公开资料、已知信息；隐藏信息不可通过前端状态或 API payload 暴露。
- 事件链：只展示玩家已知节点；未知后续不应提前泄漏。
- 人生评价：阶段性总结，不在每一轮强制弹窗。

## 4. 页面状态

- Loading：显示正在推进世界，不显示虚假的完成结果。
- AI narration unavailable：仍展示规则层结果和简短 fallback 文本。
- Empty state：新世界/新人物/暂无事件有明确引导。
- Error state：区分行动失败、模拟失败、叙事服务失败。

## 5. Demo 验收

- 主要操作在常见手机宽度下无需横向滚动。
- 核心推进按钮在单手可达区域。
- 事件详情、人物详情使用 Bottom Sheet。
- Tab 切换不丢失当前世界上下文。
